# Escritura y Oratoria

Vault de estudio para el primer parcial de H209 (UdeSA). Reúne los contenidos de las unidades 1 a 4 en páginas enlazadas sobre proceso de escritura, propiedades textuales, géneros discursivos, enunciación y subjetividad.

## Cómo empezar

Abrí este repositorio como vault en Obsidian y empezá por [Escritura.md](Escritura.md). Desde ahí podés recorrer la teoría, analizar la monografía modelo, practicar con ejercicios y consultar preguntas de examen.

La navegación entre páginas usa enlaces propios de Obsidian. Los archivos también son Markdown y pueden leerse desde GitHub.

## Alcance y fuentes

El material está pensado para estudiar el primer parcial y no cubre toda la materia. Los contenidos de las unidades 5 a 7, oratoria y el corpus de IA de los tutoriales quedan fuera de este resumen.

Las fuentes originales de la cursada no se incluyen en el repositorio público. La carpeta `raw/` está excluida mediante `.gitignore`; por eso, algunas referencias a fuentes en las páginas solo se resuelven en el vault local.
